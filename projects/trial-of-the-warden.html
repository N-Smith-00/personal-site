Trial of the Warden

Why I Built It

This was the capstone project for a virtual reality course I took in wiinter 2026, the project was meant to demonstrate application of VR priniples like object selection, manipulation, locomotion, and sim sickness avoidance.

What I Built

I built a game where the player selects weapons to take into an arena with them, then once in the arena they must face off against an enemy called the warden in order to unlock the gate at the end and escape.

Technical Details

The game was built in unity engine, many of the scripts used were created from scratch and others being derrived from code that had been done earlier in the course
